## Project Overview

A responsive Pricing Cards UI built using React. This project demonstrates dynamic data rendering using the `.map()` method and reusable components.

## Features

- Three pricing plans: Free, Plus and Pro.
- Dynamic rendering using the `.map()` method.
- Reusable PricingCard component.
- Pricing data stored in a separate JavaScript file.
- Font Awesome icons for available and unavailable features.
- Responsive layout for desktop, tablet and mobile devices.
- CSS Flexbox for card alignment and layout.
- Gradient background and button styling.
- Hover effects on pricing cards and buttons.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Font Awesome
- Vite

## Installation and Setup

1. Clone the repository:

   git clone <your-repository-url>

2. Navigate to the project folder:

   cd <project-folder>

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL provided in the terminal.
